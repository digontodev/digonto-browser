Digonto Browser
===============

A web browser on Chromium (Qt WebEngine) in the Digonto look.

- Tabs (drag to reorder, middle-click to close, Ctrl+Shift+T reopens a closed tab)
- Address bar that searches or opens addresses, with suggestions from history and bookmarks
- Bookmarks (Ctrl+D) with a bookmarks bar, history (Ctrl+H) and downloads (Ctrl+J)
- Private windows (Ctrl+Shift+N): nothing is saved
- Zoom per site, find in page, print, save as PDF, full screen, developer tools (F12)
- Asks before a site may use your camera, microphone, location or notifications
- Blocks third-party cookies by default; DuckDuckGo is the default search engine (change it in Settings)

Built in: Digonto Ad Blocker (EasyList + EasyPrivacy, on by default; switch off on the Extensions page).
Chrome extensions (Manifest V3): Extensions page or 'Add to Digonto Browser' on the Chrome Web Store.

Coming next: saved passwords, importing bookmarks, and setting Digonto Browser as the default browser.

Videos with copy protection (Netflix, Disney+, Prime Video) do not play: the free Chromium engine has no Widevine.
